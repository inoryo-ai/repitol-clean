## 1. プロダクト概要

### 1-1. 解決する課題（Problem）

営業活動において、メール作成・提案書作成・見積書作成は最も時間を消費する定型業務である。

| 課題 | 現状 |
|------|------|
| 営業メール作成に時間がかかる | 1通あたり平均15〜30分。業種・相手に応じた文面調整が必要 |
| 提案書が属人化している | 個人のスキルに依存し、品質にバラつきがある |
| 見積書のフォーマットが統一されていない | Excel手作業で作成し、転記ミスや抜け漏れが発生 |
| テンプレートの最適化が進まない | どの文面が受注に繋がったかのデータが蓄積されない |

### 1-2. ソリューション（Solution）

**SlideShot** は、AI が営業メール・提案書・見積書を自動生成する SaaS。

- 相手企業名・業種・提案内容を入力するだけで、最適な営業ドキュメントを即時生成
- 業種別に最適化されたテンプレートを AI が学習・改善し続ける
- 生成→送信→結果記録の一気通貫ワークフロー

### 1-3. 提供価値（Value Proposition）

| 対象 | 価値 |
|------|------|
| 営業マン | 営業ドキュメント作成時間を80%削減。1日5件→20件のアプローチが可能に |
| マネージャー | チーム全体の営業品質を均一化。成果データに基づく改善サイクル |
| フリーランス | プロ品質の提案書を1人で作成。受注率向上 |
| 経営者 | 営業コストの劇的削減。少人数で大量アプローチ |

## 3. 競合分析

### 3-1. 日本語営業ツール市場の現状

| カテゴリ | 代表的なサービス | 特徴 | 弱点 |
|----------|------------------|------|------|
| MA/SFA | Salesforce, HubSpot, SATORI | CRM中心、メール配信機能あり | 高額（月数万〜数十万）、導入に数ヶ月 |
| メール自動化 | 配配メール, blastmail | 一斉配信特化 | パーソナライズが弱い。1to1営業に不向き |
| AI文章生成 | ChatGPT, Notion AI | 汎用的な文章生成 | 営業特化ではない。テンプレート管理・最適化機能なし |
| 提案書作成 | Canva, Beautiful.ai | デザインテンプレート | 日本語営業文脈に最適化されていない |
| 見積書SaaS | Misoca, freee | 会計連携が強い | AI生成機能なし。定型フォーマットのみ |

### 3-2. SlideShotの差別化ポイント

| 差別化軸 | 内容 |
|----------|------|
| **営業ドキュメント3点セット** | メール・提案書・見積書を一つのツールで生成する唯一のサービス |
| **業種別AI最適化** | 業種×提案内容の組み合わせでテンプレートを自動最適化。使うほど精度が上がる |
| **日本語営業文脈への特化** | 敬語レベル・季節の挨拶・業界用語など、日本のビジネス慣習に完全対応 |
| **圧倒的な低価格** | 月額1,980円〜。SFA/MAの1/10以下の価格で導入可能 |
| **即日導入・即日効果** | アカウント作成から5分で最初の営業メールを生成。学習コストほぼゼロ |
| **データモート** | 利用データが蓄積するほど業種別テンプレートの精度が向上し、後発が追いつけない |

## 5. API設計

### POST `/api/generate/email`
営業メール生成。業種・相手企業・提案内容を入力→件名+本文を返却

### POST `/api/generate/proposal`
提案書生成。案件情報を入力→Markdown形式の提案書を返却

### POST `/api/generate/estimate`
見積書生成。項目リストを入力→AI補完付きの見積書を返却

### GET `/api/documents`
生成履歴一覧。type/page/limitでフィルタ

### GET/PUT/DELETE `/api/documents/[id]`
ドキュメントの詳細取得・更新・削除

### POST `/api/export/pdf`
ドキュメントをPDF化してURL返却
